Mission Scenario

You are an operator for the Hack Smarter Red Team, currently conducting a black-box assessment on a client's external login portal. As part of the initial reconnaissance phase, our OSINT analysts have compiled a list of potential usernames.

You need to identify which one is a valid username for the web application.

Have to Obtain:

  • valid Username

Vulnerability Assessment

WebApp

We gonna run Caido. On caido we dont have rate limiting for bruteforce attacks. But you are free to use Burp Suite if you like it more.

Firstly we have to upload our username wordlist into caido

If you are using Kali Linux you have deafaulted installed wordlists. This wordlist you can find inside /usr/share/wordlists/wfuzz/others/names.txt

Otherwise you can use copy of this directory on this github repo: Wordlist

Then go to password reset. And sent the history request to automate.

In the settings set up # of workers to 5. We dont want to overload the WebApp, because then we are risking we gonna get false positive or even skip it.

Now when we set up our attack payload we are free to run it and start bruteforcing valid username.

The username jo** took more time so this should be the valid username. And it is a valid username.
